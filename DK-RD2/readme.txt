Title: DK-RD2 — Duo-Kinetic Relativistic Dynamics 2.0
-----------------------------------------------------

DK-RD2 is a thermodynamic–relativistic cosmological model that explains the
accelerated expansion of the Universe without invoking dark energy or cold dark
matter. The acceleration emerges from a dynamic gravitational coupling
Gab(T, v), explicitly dependent on temperature T and velocity v, which modifies
the Friedmann equation through the matter–energy–temperature cycle rather than
through a cosmological constant Λ.

The code in this package implements the full DK-RD2 pipeline used in the
February 2026 manuscript, including all figures and statistics presented in the
paper. Every figure, table, and metric can be regenerated by running the main
driver script.


Files and structure
-------------------

- DK_RD2_Core.py
    Core physics engine:
    - Universal constants
    - Dynamic coupling Gab(T, v)
    - Background ODEs and distances
    - Growth factor and helper routines

- DK_RD2_CLASS.py
    Interface to the CLASS Boltzmann solver:
    - Generates Planck 2018 ΛCDM CMB TT reference spectra
    - Applies geometric morphing onto the DK-RD2 background (no refit, no new
      parameters)

- DK-RD2.py
    Main driver / orchestrator:
    - Loads datasets from ./data/
    - Calls DK-RD2 kernels and (optionally) CLASS
    - Generates all figures and CSV tables under ./evidence/

- /data/
    Input datasets used by the pipeline (not always included in this archive):
    - SCP Union2 (SN Ia)
    - Pantheon+SH0ES
    - H(z) compilation (hubble_observations.csv)
    - DESI coadds for low-z validation
    - CASTLES-like strong-lensing sample
    - fσ8(z) redshift-space distortion measurements (fsigma8.dat)
    - SPHEREx-like mock products for thermo-gravity tests

- /evidence/
    Auto-generated outputs:
    - DK-RD2_image_XX.*  (PNG figures)
    - DK-RD2_table_XX*.csv (per-figure tables)
    - *_stats.csv with χ², MSE, AIC, BIC, k, n, etc.


What the code does (high-level)
-------------------------------

The DK-RD2 engine:

- Evaluates the effective gravitational coupling Gab(T, v)
- Solves for the expansion history H(z) on the DK-RD2 background
- Computes luminosity distances and distance modulus μ(z)
- Evaluates the linear-growth observable fσ8(z)
- Performs CMB TT geometric consistency tests via CLASS-based remapping
- Tests strong-lensing geometry with CASTLES-like lenses
- Validates low-z behavior using DESI-based Hubble-law proxies
- Computes diagnostic statistics (χ², RMSE, AIC, BIC) for DK-RD2 and ΛCDM
  under *equal parameter count* (no extra cosmological parameters for DK-RD2)


Figure overview (driver DK-RD2.py)
----------------------------------

The main script DK-RD2.py generates up to nine figures. Each one can be
selected individually at runtime (see the next section).

  1 — Figure 01: Solar multi-wavelength bands and thermodynamic–relativistic
                 amplification Gab(T, v)/G0. Builds a table of EM bands and
                 representative particles in different thermal environments
                 (solar core, near surface, corona, interstellar/CMB) and a
                 vertical Gab(T, v) thermal map.

  2 — Figure 02: Union2 Type Ia supernovae Hubble diagram μ(z) vs z, comparing
                 ΛCDM and DK-RD2 predictions, with residuals and basic
                 statistics saved to CSV.

  3 — Figure 03: CMB TT angular power spectrum. Planck 2018 TT data and the
                 Planck best-fit ΛCDM CLASS template, geometrically remapped
                 onto the DK-RD2 background (same microphysics, no refit),
                 with comparison tables and stats.

  4 — Figure 04: H(z) vs models. Observational Hubble-parameter compilation
                 (hubble_observations.csv) contrasted with ΛCDM and DK-RD2
                 expansion histories; outputs figure, stats CSV and an
                 effective Ω_Λ,eff comparison table.

  5 — Figure 05: Strong-lensing (SIS) using CASTLES-like lenses. Einstein
                 radius θ_E computed with constant G0 (ΛCDM) and with
                 Gab(T, v) (DK-RD2). Saves the figure, lensing table,
                 amplification ratios and statistics.

  6 — Figure 06: Pantheon+ SH0ES supernova sample. Distance modulus μ(z) from
                 Pantheon+SH0ES.dat compared with DK-RD2 predictions, together
                 with per-object / per-bin statistics stored in CSV files.

  7 — Figure 07: DESI low-z validation (Hubble-law proxy). Uses DESI coadded
                 spectra (DESI_TILES) to build a low-redshift μ(z) proxy,
                 compares ΛCDM and DK-RD2 local slopes (q0), and produces
                 residual plots plus summary tables (comparison, q0 fits,
                 RMSE evolution).

  8 — Figure 08: Linear growth observable fσ8(z). Solves the DK-RD2 growth ODE
                 (normalized so that D(0) = 1) and compares fσ8(z) with
                 compiled redshift-space distortion measurements from
                 fsigma8.dat, saving the figure, data table and stats.

  9 — Figure 09: SPHEREx thermo-gravity proxy. Reads mock SPHEREx-like data
                 from data/SPHEREX and produces a thermo-gravity diagnostic
                 figure together with a summary CSV table.


Running the code and selecting figures
--------------------------------------

From a terminal in the directory containing DK-RD2.py and the core modules:

    python DK-RD2.py

On startup, the script:

1. Creates the ./evidence/ folder if it does not exist.
2. Prints an ASCII banner and a list of available figure IDs.
3. Shows the current selector (default: "all").
4. Prompts for a new selector string.

Selector syntax:

- Empty string or "all":
    runs all figures (1–9).

- "0":
    treated as "all" (runs all figures).

- "1,2":
    runs only Figure 01 and Figure 02.

- "1-4,7,9":
    runs Figures 01, 02, 03, 04, 07 and 09.

The selection is parsed into a set of integers and only those figures are
generated. Each figure reports the paths of the PNG and CSV files it writes
under ./evidence/.


Dependencies and requirements
-----------------------------

- Python >= 3.12.4
- numpy
- scipy
- matplotlib
- pandas
- astropy
- CLASS (for Figure 03 only; CMB TT reference spectra)

To install the basic Python dependencies you can use:

    pip install numpy scipy matplotlib pandas astropy

CLASS is required *only* for the CMB Figure 03. If CLASS is not installed
or not available in your PATH, the driver will skip Figure 03 when requested
and print a message explaining that CLASS is needed for the CMB TT morphing
step. All other figures can still be generated normally.


Scientific philosophy (short)
-----------------------------

- No cosmological constant Λ is introduced in the DK-RD2 branch.
- No fitted Ω_DM or dark-energy density parameters are used.
- DK-RD2 is evaluated with Ω_m,DK = 1, and all apparent “dark sector”
  effects emerge from the thermodynamic–relativistic modulation in Gab(T, v).
- ΛCDM parameters (Planck 2018 baseline) are used only as a reference model
  for comparison under identical parameter count (k = 0).
